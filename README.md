# מעקב מנויי שקי מזון - אניפט

כלי פנימי לצוות החנות: טבלה אחת שמרכזת את כל הלקוחות במנוי לשקי מזון, כדי לדעת מתי כדאי לשלוח להם הודעת וואטסאפ שמציעה משלוח, בלי לחפש כל פעם מחדש בתוכנת המשרד האחורי.

## מבנה הפרויקט

- `docs/` - עמוד סטטי (HTML/CSS/JS ללא framework), עברית RTL, מותאם לנייד. מוגש כ-GitHub Pages ישירות מהתיקייה הזו בענף `main`.
- `worker/` - Cloudflare Worker + D1 (מסד נתונים) שמחזיק את הנתונים המשותפים לכל הצוות, מכל מכשיר.

## שלושת הטבלאות

1. **לקוחות במעקב** - כל הלקוחות שלא ב"המתנה", צבועים לפי תאריך משוער למשיכה הבאה (מחושב מממוצע ההיסטוריה האישית שלהם): ירוק = אפשר לשלוח עכשיו, כתום = בקרוב, אדום = יש עוד זמן, אפור = אין עדיין מספיק היסטוריה (פחות משתי משיכות רשומות).
2. **ממתינים** - לקוחות שסימנתם "עדיין לא צריך" (עם תאריך חזרה). כשמסמנים שהם משכו שק, הם חוזרים אוטומטית לטבלה הראשית.
3. **נשאר שק אחרון** - כל לקוח עם שק אחד או פחות במנוי. כפתור "חודש" מוסיף 6 שקים למה שנשאר.

מספר טלפון הוא שדה חובה וייחודי - לא ניתן לצרף את אותו לקוח פעמיים.

## פיתוח מקומי

```bash
# הרצת השרת (Worker + D1 מקומי)
cd worker
npm install
npx wrangler d1 migrations apply anipet-subscriptions-db --local
npx wrangler dev --port 8787 --local

# בטרמינל נפרד - הרצת העמוד
cd ..
npx serve docs -l 5500
```

פתחו http://127.0.0.1:5500 בדפדפן.

## פריסה לענן (production)

1. התחברות לחשבון Cloudflare (חד פעמי, צריך להריץ בטרמינל אינטראקטיבי):
   ```bash
   cd worker
   npx wrangler login
   ```
2. יצירת מסד הנתונים האמיתי (חד פעמי) והחלפת ה-`database_id` שיוחזר בתוך `worker/wrangler.jsonc`:
   ```bash
   npx wrangler d1 create anipet-subscriptions-db
   ```
3. הרצת המיגרציה על מסד הנתונים האמיתי:
   ```bash
   npx wrangler d1 migrations apply anipet-subscriptions-db --remote
   ```
4. פריסת ה-Worker:
   ```bash
   npx wrangler deploy
   ```
   הפקודה תדפיס כתובת מהצורה `https://anipet-subscriptions.<your-subdomain>.workers.dev`.
5. עדכון `docs/config.js` עם הכתובת שהתקבלה, לפני שמפעילים GitHub Pages (ראו למטה).

## הפעלת GitHub Pages

לאחר יצירת הריפו וה-push הראשוני:
1. בדף הריפו ב-GitHub: Settings → Pages.
2. Source: Deploy from a branch.
3. Branch: `main`, תיקייה: `/docs`.
4. שמירה - האתר יהיה זמין תוך דקה-שתיים בכתובת שתופיע שם (בדרך כלל `https://smkrot3-sudo.github.io/anipet-subscriptions/`).

## הערת פרטיות

הטבלה מכילה שמות ומספרי טלפון אמיתיים של לקוחות, ולפי בקשת המשתמש הוגדרה **ללא הגנת סיסמה** על העמוד. כדאי לוודא שהקישור לעמוד לא מופץ מעבר לצוות החנות, ולשקול הגנה בהמשך אם הצורך יעלה.
